# gomoku 五子棋

纯本地、零依赖（仅 Python 标准库）的五子棋人机对战小游戏。

## 玩法

- 你执黑（●）先行，AI 执白（○）后行，横 / 竖 / 斜连成 5 子即胜。
- 坐标是「列字母 + 行数字」，如 `H8`（大小写不限）。
- 非法坐标（格式错、超出棋盘、已有棋子）会重新提示，不会崩溃。

## 运行

需要 Python 3.10+，无需安装任何第三方包：

```bash
# 人机对战（15×15）
python3 -m gomoku

# 13×13 棋盘
python3 -m gomoku --size 13

# 固定剧本演示（黑方斜线连五获胜）
python3 -m gomoku --demo

# AI 自己跟自己下一盘（必有结果：一方获胜或和棋）
python3 -m gomoku --selfplay --seed 1
```

## AI 说明：威胁启发式（非 minimax）

AI 不做搜索树，只评估每个空位的“威胁等级”，按以下优先级落子：

1. 自己能连五 → 直接取胜
2. 对方下手能连五 → 堵必胜点
3. 堵对方的四（活四 / 冲四）
4. 自己造活四
5. 堵对方的活三
6. 自己造活三
7. 攻守综合评分最高点（进攻权重略高于防守，靠近中心优先，微小随机量打破平局）

候选点只取已有棋子周围两圈，保证 15×15 上每步都是毫秒级。

## 已知局限（诚实版）

- 启发式不是 minimax，没有向前看多步：**会被有计划的双重威胁 / 圈套击败**，高手赢它不难。
- 没有开局库，第一手永远下天元附近。
- 活四（两端都是必胜点）理论上防不住，AI 只能堵一端拖延——这是规则决定的，不是 bug。
- `--selfplay` 里双方是同一个 AI，水平相当，对局偏长属正常。
